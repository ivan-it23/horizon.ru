## Описание

Система учёта приборов АМК «Горизонт» — это современная веб-платформа для централизованного управления данными геофизических приборов индукционного каротажа. Система обеспечивает полный жизненный цикл приборов от производства до прекращения эксплуатации.

### Основные возможности
- **Учёт приборов** — создание, поиск, редактирование
- **Жизненный цикл** — производство, испытания, ремонт, контроль
- **Файловая система** — загрузка и управление документами
- **Экспорт данных** — выгрузка в Excel формат
- **AI-помощник** — естественно-языковые запросы к данным
- **Мессенджер** — внутренняя система сообщений
- **Управление пользователями** — роли и права доступа

## Быстрый старт

### 1. Требования
- PHP 7.4+
- MySQL 5.7+
- Веб-сервер (Apache/Nginx)

### 2. Установка
```bash
# Клонируйте репозиторий
git clone [repository-url]

# Настройте базу данных
mysql -u root -p < ivanbohg_account.sql

# Настройте конфигурацию
cp config.php.example config.php
# Отредактируйте config.php с вашими настройками БД
```

### 3. Конфигурация
Отредактируйте `config.php`:
```php
// Настройки базы данных
define('DB_HOST', 'localhost');
define('DB_USERNAME', 'your_username');
define('DB_PASSWORD', 'your_password');
define('DB_NAME', 'your_database');

// API ключ для AI-агента
define('OPENROUTER_API_KEY', 'your_api_key');
```

### 4. Запуск
Откройте в браузере: `http://your-domain/index.php`

## AI-агент

Система включает интеллектуального помощника с модульной архитектурой.

### Возможности
- **Поиск приборов** по естественному языку
- **Статистика и аналитика** данных
- **Генерация отчётов** в Markdown (заголовки `###`/`####`, маркированные списки, жирный текст; без эмодзи, в строгом корпоративном стиле)
- **Контекстные диалоги** с памятью о предыдущих запросах

### Архитектура
- **QueryAnalyzer** — анализ запросов
- **QueryExecutor** — выполнение запросов к БД
- **DeviceInfoManager** — работа с данными приборов
- **ResponseFormatter** — форматирование ответов
- **ContextManager** — управление контекстом диалога
