## 🔧 ИСПОЛЬЗОВАНИЕ

### **Для защиты новой страницы:**

```php
<?php
// Подключаем систему безопасности
require_once __DIR__ . '/security_init.php';

// Для обычной страницы
initPageSecurity('your_page.php');

// Для админской страницы
initPageSecurity('admin_page.php', true);

// ... код страницы ...

// В конце HTML добавляем клиентскую защиту
echo generateSecurityScript();
?>
```

### **Для защиты контроллера:**

```php
<?php
namespace App\Controller;

use App\Controller\BaseController;

class YourController extends BaseController
{
    public function yourMethod(): void
    {
        // Проверка авторизации
        $this->requireAuth();
        
        // Rate limiting
        if (!$this->checkRateLimit($this->getClientIP(), 'your_action', 10, 60)) {
            $this->handleError('Rate limit exceeded', [], 429);
            return;
        }
        
        // Валидация данных
        $data = $this->sanitizeString($_POST['data'] ?? '');
        
        // Логирование
        $this->logSecurityEvent('your_action_performed', ['data' => $data]);
        
        // ... логика метода ...
    }
}
```

## 📈 МОНИТОРИНГ И ЛОГИРОВАНИЕ

### **Логируемые события:**
- `auth_login_success/failed` - авторизация
- `page_accessed` - доступ к защищённым страницам
- `rate_limit_exceeded` - превышение лимитов
- `device_created/updated` - операции с приборами

## 🔍 ДИАГНОСТИКА И ТЕСТИРОВАНИЕ

### **Проверка системы безопасности:**

1. **Тест авторизации:**
   - Попробуйте открыть `AccountingOfDevices2.php` без авторизации

   - Должны быть очищены и валидированы
